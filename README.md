## Описание проекта

Система подписки на онлайн-сервис дает возможность видеть пользователей, подисавшихся на платные тарифы приложения, регистрировать новых пользователей, получать имена активных подписчиков и общее количество юзеров приложения.

## Описание пользователей (клиентов)

клиенты бывают бесплатные, стандартные и премиальные. У последних есть доступ к закрытым бета-функциям.
